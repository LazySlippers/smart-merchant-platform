# 单商场消费者端

消费者站点服务于一家百货商场，商品类别和规格由后台维护，不限定茶饮品类。

部署者在 `frontend/apps/consumer-web/.env.local` 配置：

```dotenv
VITE_CONSUMER_TENANT_ID=商场对应的租户ID
```

开发服务会读取该配置；生产部署需重新构建。应用同时在 `src/storefront.json` 保存默认商场，环境配置缺失或无效时使用它，初始化脚本会同步写入两处。网址里的空值、占位文字和无效租户参数会自动移除并回到默认商场。有效的显式租户参数仍用于兼容联调链接。

顾客只访问 `/`，无需扫码、填写品牌参数或选择商场。首次访问自动加载该商场的可用门店；门店选择保存在本机，普通访问不往网址追加门店参数。

首页使用通用百货购物视觉。商品优先显示后台图片，缺图时显示中性商品占位；分类、商品名称、规格、价格、库存均来自真实接口。原来的茶饮图片只保留在显式 `preview=1` 的历史演示版中。

带有 `tenantId` / `storeId` 的原联调链接继续兼容，但不要求普通消费者使用。
